# 连续性记录模板

按需要单独建立，简单场景可并入单元计划。必须区分计划状态和从视频观察到的状态。

- 场景/单元：
- 记录类型：计划 / 实际观察（填写其一）：
- 依据：原文、源视频及SHA256、精确时间点、可靠全景/中全景位置：
- 场景固定结构、通道、门窗和障碍物：
- 人物与固定环境的位置关系：
- 轴线、机位在哪一侧、画面左右与视线关系：
- 人物身体自身左右、手侧、朝向、动作阶段：
- 道具唯一数量、归属、持物手、转手/离手/落点：
- 伤口、血迹、绷带及衣物状态：
- 发声人、完整原句、句尾和声音接点：
- 结束时实际可见状态：
- 被裁切/遮挡而未知的部分：
- 下一单元依赖哪些已确认事实：
- 与制作锁冲突的事实及可继续的范围：

不能以计划中的末态代替视频实际结果；不能用局部特写推断画面外站位。
